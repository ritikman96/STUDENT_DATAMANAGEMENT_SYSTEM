# Student Management System

A simple **Student Management System** built with **Python, Tkinter, and Pandas**.

## Features

* Add new students
* Search students by ID
* Update student details
* Delete student records
* Calculate average marks
* Find the top scorer
* Search students by course
* Display student records in a Tkinter table

## Technologies Used

* Python
* Tkinter
* Pandas
* Pillow (PIL)

## Project Structure

```text
Student-Management-System/
│
├── gui.py
├── main.py
├── background.jpg
└── README.md
```

## How to Run

Install the required libraries:

```bash
pip install pandas pillow
```

Then run the frontend:

```bash
python frontend.py
```

The frontend connects with `main.py` to manage student data.
